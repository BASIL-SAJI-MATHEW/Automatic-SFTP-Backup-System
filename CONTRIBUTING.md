# Contributing to BSM Automatic SFTP Backup System

First off, thank you for considering contributing to the most advanced backup system built by BSM. We value every contribution—from bug reports to new features!

## Development Process
1. **Fork the repo** and create your branch from `main`.
2. Ensure you have the latest Node.js and TypeScript installed.
3. Run `npm install` to get the dependencies.
4. If you've added code that should be tested, add tests.
5. Ensure the test suite passes (if implemented).
6. Format your code correctly: Follow the existing ESLint and Prettier configs.

## Push your changes
Ensure you use conventional commits:
`feat: added new aws s3 bucket integration`
`fix: corrected edge case for mongo dump sizes`
