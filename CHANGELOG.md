# Changelog

All notable changes to the **BSM Automatic SFTP Backup System** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-03-30
### Added
- Initial release of the BSM Automatic SFTP Backup System.
- Multi-server SFTP synchronization.
- Database automatic dumps (MySQL, PostgreSQL, MongoDB).
- Discord Webhook AI integration with rich embeds.
- AES-256-CBC Encryption module.
- Auto-Cleanup Retention Engine.
- YAML configuration system.
- Secure environmental variables usage.
